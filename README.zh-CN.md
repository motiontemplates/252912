## 技术原理

- 声明的运行配置：html-canvas/1。
- 通过模板参数和预设，将本期文字、数据或素材映射到已有动画工程。
- 已声明时长随本期内容适配，最终节奏由包内制作计划确定。

样片时长: **66s**. 已声明输出为 1920 × 1080，60 fps；公开样片 66 秒。 按实际包的参数边界制作；增加素材不会自动增加场景。
